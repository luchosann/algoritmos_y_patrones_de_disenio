# Algoritmos y patrones de disenio

 Descripción de la Unidad Curricular

Esta unidad curricular tiene como propósito proporcionar a los estudiantes una comprensión sólida de los patrones de diseño de software y de las estructuras de datos avanzadas, promoviendo su aplicación en el desarrollo de soluciones mantenibles, reutilizables y escalables.

A través del análisis de problemas, la evaluación de alternativas de diseño y la implementación de soluciones, se busca fortalecer competencias vinculadas al pensamiento computacional, la abstracción, la modelización y las buenas prácticas de ingeniería de software.

Durante el curso se trabajará con ejercicios y casos prácticos orientados a contextos reales, culminando en el desarrollo de una aplicación completa que integre estructuras de datos, principios de diseño y patrones de software.


 Módulo 1: Patrones de diseño creacionales

    Patrón Singleton
    Patrón Factory Method
    Patrón Abstract Factory
    Patrón Builder
    Patrón Prototype


 Módulo 2: Patrones estructurales y de comportamiento

Patrones estructurales

    Adapter
    Decorator
    Composite
    Facade
    Proxy
    DAO

Patrones de comportamiento

    Observer
    Strategy


 Módulo 3: Aplicación completa CRUD

    Introducción al proyecto CRUD
    Diseño de la aplicación
    Patrones creacionales
    Patrones estructurales
    Interacción desde consola
    Pruebas y validación


 Módulo 4: Estructuras de datos avanzadas

    Introducción a estructuras de datos
    Listas enlazadas
    Pilas (Stack)
    Colas (Queue)
    Hash
    Algoritmos de ordenamiento


 Módulo 5: Algoritmos avanzados

    Árboles
    Recorrido de árboles


    Conocimientos adicionales (Grafos, clasificación avanzada de algoritmos, búsqueda y recuperación de datos,  optimización y análisis de algoritmos, recursividad y divide y vencerás) No considerados en evaluación.
